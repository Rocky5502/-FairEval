# FairEval result-table architecture

This document freezes the paper-facing table plan before empirical results are available. Numerical values must come from frozen analysis artifacts; do not type result numbers into LaTeX by hand.

## Main-paper anchors

### Table M1 — RQ1 + RQ2 primary effects

File: `paper/result_tables/rq12_main_table.tex`

Generated by: `scripts/render_result_tables.py`

Primary source: `results/.../inference.jsonl`

Layout: eight model rows (six hosted + two local) and five dataset columns:

- RQ1: MovieLens-1M and Last.fm-1K observed-vs-counterfactual nDCG@10;
- RQ2: Personality 2018, Music Master/BFI-2, and REASONER true-vs-shuffled PVA in nDCG@10.

Each populated cell carries the paired mean, 95% paired-bootstrap CI, and Holm-adjusted paired-permutation p-value. This table is the primary compact cross-model/cross-dataset results anchor.

### Table M2 — RQ3 reliability + RQ4 mitigation

File: `paper/result_tables/rq34_main_table.tex`

Sources:

- `rq3_variation_summary.jsonl` from `scripts/analyze_rq3.py`;
- `rq4_pair_artifact.json` from `scripts/analyze_rq4.py`;
- a future dedicated identity-irrelevance-prompting artifact before that row can be populated.

RQ3 rows summarize the registered one-factor robustness blocks without selecting a best prompt/cue/order. RQ4 reports the global validation-frozen contextual-PAIR operating point. Test outcomes may never select or relax that point.

## Compact supporting tables

These four files are generated and shipped to Overleaf, but are promoted into the 12-page body only if the real findings justify the space.

1. `coverage_table.tex` — dataset users/models/conditions and persistent-invalid rate from `user_condition.jsonl`.
2. `trait_ablation_table.tex` — RQ2 C5 one-trait robustness from `trait_inference.jsonl` produced by `scripts/analyze_rq2_traits.py`.
3. `fairsynth_table.tex` — FairSynth-360 identity/personality sanity checks, with hosted and local strata kept separate.
4. `whitebox_table.tex` — exploratory local token-score correlations from `scripts/analyze_local_whitebox.py`; never described as calibrated uncertainty.

## Generation commands

Before experiments, regenerate only the contracts:

```bash
python scripts/render_result_tables.py --contracts-only
```

After all frozen analysis artifacts exist:

```bash
python scripts/render_result_tables.py \
  --inference-jsonl results/analysis/core/inference.jsonl \
  --trait-inference-jsonl results/analysis/rq2-traits-v1/trait_inference.jsonl \
  --rq3-summary-jsonl results/analysis/rq3/rq3_variation_summary.jsonl \
  --rq4-artifact-json results/analysis/rq4/rq4_pair_artifact.json \
  --fairsynth-inference-jsonl results/analysis/fairsynth360-v1/inference.jsonl \
  --whitebox-summary-jsonl results/analysis/local-whitebox/whitebox_summary.jsonl \
  --user-condition-jsonl results/analysis/core/user_condition.jsonl
```

The final-render mode intentionally requires every artifact listed above. Missing artifacts are a hard error rather than a reason to insert a hand-entered value or silently leave an unexplained dash.

## Interpretation guards

- RQ1 list change alone is not a fairness result.
- RQ2 C5 rows are robustness hypotheses; they do not replace true-vs-shuffled PVA as the primary RQ2 estimand.
- FairSynth is never pooled with observed-demographic or measured-psychometric estimates.
- White-box diagnostics are descriptive/uncalibrated and outside confirmatory Holm families.
- RQ4 uses one global validation-frozen PAIR point with the preregistered utility-retention floor; no test-set or per-model tuning.
- The four compact tables may move in/out of the main body for page-budget reasons, but their underlying analysis artifacts and generation code remain unchanged.
